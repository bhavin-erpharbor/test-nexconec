# Accounting ZIP Export

Adds a wizard under Accounting > Reporting > Export Accounting ZIP to download posted accounting documents as a ZIP file.

Default date range is previous month. The ZIP includes PDFs and an optional summary CSV.

## Install

1. Copy `accounting_zip_export` into your Odoo addons path.
2. Update Apps list.
3. Install/Upgrade module `Accounting ZIP Export`.

## Usage

Go to Accounting > Reporting > Export Accounting ZIP.
